## Périmètre (spec §15)

**Possède** : temps fondateur consommé par opportunité (§6), information
imparfaite progressive sur le budget/attentes du compte (§7,
`Estimate{value,uncertainty}`), `AccountProposal`/
`AccountNegotiationDecision` (§8), résolution déterministe
accept/counter/withdraw, transition `"researching"` → `"negotiating"` →
`"won"`/`"declined-by-player"`.

**Ne possède PAS** : aucune consommation de capacité réelle, aucun CA —
un compte `"won"` porte un `AccountContract` signé mais celui-ci n'a
**aucun effet** sur `businessResolution.ts` tant que M11.2.4.3 n'existe
pas (contrat "papier"). Aucune conversion en `StrategicAccount` confirmé
(`OwnedBusiness.strategicAccounts` reste `[]` — cette conversion est un
détail d'affichage/relation reporté à M11.2.4.3/4, la spec ne l'exige pas
avant que le contrat ait un effet réel).

**Critère de complétude** : mener une négociation complète de bout en
bout et obtenir un contrat signé déterministe et explicable, sans
qu'aucune ligne de `businessResolution.ts::resolveBusinessMonth` ne soit
touchée.

## Décisions de conception verrouillées

1. **Budget réel du compte, jamais persisté, dérivé à la demande** :
   `deriveTrueOpportunityBudget(opportunityId, referencePrice)` — pure,
   seedée sur `deriveSeed(0, "strategic-account-budget", opportunityId)`,
   donc stable pour un id d'opportunité donné, aucune migration
   nécessaire (rien de nouveau à persister pour la vérité elle-même).
2. **Résolution de négociation déterministe** (spec §8, principe 13) :
   `resolveAccountNegotiationDecision` compare la proposition du joueur
   au budget réel (`price <= maxAcceptablePrice`, `qualityCommitment >=
   minAcceptableQuality`) — jamais de jet de probabilité sur l'issue.
   Rejet ⇒ le compte répond avec une contre-proposition ancrée sur son
   budget réel (`lastAccountProposal`), jamais un refus muet.
3. **Information imparfaite réutilise `estimate()` de `intelligence.ts`**
   (exportée, jusqu'ici privée au module) — adaptateur : le nombre
   d'heures de recherche investies (`researchHoursInvested`, persisté,
   cumulatif) est converti en un « niveau de compétence équivalent »
   0-100 (`hours / MAX_RESEARCH_HOURS_FOR_FULL_CONFIDENCE * 100`,
   plafonné), passé à `estimate()` — aucune nouvelle courbe de bruit
   inventée.
4. **Champs additifs sur `StrategicAccountOpportunity`** (migration
   défensive requise) : `researchHoursInvested: number` (`?? 0`),
   `budgetEstimate: {price,volume,qualityCommitment}: Estimate` par
   champ (`?? null`, régénéré si absent — voir Tâche 5), 
   `lastAccountProposal: AccountProposal | null` (`?? null`),
   `contract: AccountContract | null` (`?? null`).
5. **Nouvelle action joueur** `StrategicAccountAction` (`types/strategicAccount.ts`,
   même esprit que `OfferAction`) : `invest-time` (consomme le même
   budget de temps fondateur partagé que `founderHoursAllocated`/
   `founderProspectionHoursAllocated`/`develop`, validé dans
   `validateActions`), `propose`/`counter` (soumet une
   `AccountProposal`), `accept` (accepte la dernière contre-proposition
   du compte), `withdraw` (abandon, `"declined-by-player"`). Portée sur
   `BusinessAction.strategicAccountActions?: readonly StrategicAccountAction[]`.
6. **Application dans `simulateMonth.ts`**, jamais `businessResolution.ts`
   (même raison qu'en M11.2.4.1 : c'est le point d'orchestration des
   actions par entreprise, pas le calcul économique). Ordre : actions du
   joueur sur les opportunités existantes appliquées AVANT l'apparition
   de nouvelles opportunités (cohérent avec `applyOfferActions` avant le
   calcul économique du mois).
7. **UI** : extension de `StrategicAccountsScreen` (pas un nouvel écran
   séparé) — pour une opportunité `"researching"`/`"negotiating"` :
   compteur d'heures investies + saisie d'heures supplémentaires,
   fourchette de budget estimée (`value ± uncertainty`, formatée en
   euros/unités, jamais un pourcentage de réussite — spec §7, principe
   13), formulaire de proposition (prix/volume/qualité/durée), affichage
   de la dernière contre-proposition du compte si `"negotiating"`,
   actions Proposer/Accepter/Contre-proposer/Abandonner. Jamais de
   `status` brut ni d'id technique.

```ts
export const MAX_RESEARCH_HOURS_FOR_FULL_CONFIDENCE = 40;

export function deriveTrueOpportunityBudget(opportunityId: string, referencePrice: number) {
  const rng = createRng(deriveSeed(0, "strategic-account-budget", opportunityId));
  return {
    maxAcceptablePrice: referencePrice * rng.nextFloat(0.9, 1.5),
    expectedVolume: rng.nextFloat(20, 80),
    minAcceptableQuality: rng.nextFloat(50, 80),
  };
}

export function computeBudgetEstimate(opportunityId: string, referencePrice: number, researchHoursInvested: number) {
  const truth = deriveTrueOpportunityBudget(opportunityId, referencePrice);
  const confidenceEquivalent = clamp((researchHoursInvested / MAX_RESEARCH_HOURS_FOR_FULL_CONFIDENCE) * 100, 0, 100);
  const rng = createRng(deriveSeed(0, "strategic-account-estimate", opportunityId));
  return {
    price: estimate(truth.maxAcceptablePrice, confidenceEquivalent, rng.fork("price")),
    volume: estimate(truth.expectedVolume, confidenceEquivalent, rng.fork("volume")),
    qualityCommitment: estimate(truth.minAcceptableQuality, confidenceEquivalent, rng.fork("quality")),
  };
}
```

**Implémentation minimale** :
```ts
export const NEGOTIATION_PRICE_TOLERANCE = 1.0;

function referencePriceFor(segmentId: string, family: EconomicFamily): number {
  return getMarketSegments(family).find((s) => s.id === segmentId)?.referencePrice ?? 0;
}

function signContract(opportunity: StrategicAccountOpportunity, proposal: AccountProposal, date: GameDate): StrategicAccountOpportunity {
  return {
    ...opportunity,
    status: "won",
    lastAccountProposal: null,
    contract: { price: proposal.price, volume: proposal.volume, qualityCommitment: proposal.qualityCommitment, durationMonths: proposal.durationMonths, monthsRemaining: proposal.durationMonths, signedAt: date },
  };
}

export function resolveAccountNegotiationDecision(
  opportunity: StrategicAccountOpportunity,
  family: EconomicFamily,
  decision: AccountNegotiationDecision,
  date: GameDate,
): StrategicAccountOpportunity {
  if (opportunity.status !== "researching" && opportunity.status !== "negotiating") {
    throw new RangeError(`resolveAccountNegotiationDecision: "${opportunity.id}" au statut "${opportunity.status}", négociation impossible.`);
  }
  if (decision.action === "withdraw") {
    return { ...opportunity, status: "declined-by-player", lastAccountProposal: null };
  }
  if (decision.action === "accept") {
    if (!opportunity.lastAccountProposal) {
      throw new RangeError(`resolveAccountNegotiationDecision: aucune contre-proposition à accepter pour "${opportunity.id}".`);
    }
    return signContract(opportunity, opportunity.lastAccountProposal, date);
  }
  const referencePrice = referencePriceFor(opportunity.segmentId, family);
  const budget = deriveTrueOpportunityBudget(opportunity.id, referencePrice);
  const { proposal } = decision;
  const accepted = proposal.price <= budget.maxAcceptablePrice * NEGOTIATION_PRICE_TOLERANCE && proposal.qualityCommitment >= budget.minAcceptableQuality;
  if (accepted) return signContract(opportunity, proposal, date);
  return {
    ...opportunity,
    status: "negotiating",
    lastAccountProposal: {
      price: budget.maxAcceptablePrice,
      volume: budget.expectedVolume,
      qualityCommitment: budget.minAcceptableQuality,
      durationMonths: proposal.durationMonths,
    },
  };
}

export function applyResearchHours(opportunity: StrategicAccountOpportunity, hours: number, family: EconomicFamily): StrategicAccountOpportunity {
  if (hours < 0) throw new RangeError(`applyResearchHours: hours=${hours} doit être >= 0.`);
  if (opportunity.status !== "researching" && opportunity.status !== "negotiating") return opportunity;
  const researchHoursInvested = opportunity.researchHoursInvested + hours;
  const referencePrice = referencePriceFor(opportunity.segmentId, family);
  return { ...opportunity, researchHoursInvested, budgetEstimate: computeBudgetEstimate(opportunity.id, referencePrice, researchHoursInvested) };
}

export function applyStrategicAccountActions(
  opportunities: readonly StrategicAccountOpportunity[],
  actions: readonly StrategicAccountAction[],
  family: EconomicFamily,
  date: GameDate,
): readonly StrategicAccountOpportunity[] {
  let result = opportunities;
  for (const action of actions) {
    const index = result.findIndex((o) => o.id === action.opportunityId);
    if (index === -1) throw new RangeError(`applyStrategicAccountActions: opportunité "${action.opportunityId}" introuvable.`);
    const opportunity = result[index]!;
    const updated =
      action.kind === "invest-time"
        ? applyResearchHours(opportunity, action.hours, family)
        : resolveAccountNegotiationDecision(
            opportunity,
            family,
            action.kind === "accept" || action.kind === "withdraw" ? { action: action.kind } : { action: action.kind, proposal: action.proposal },
            date,
          );
    result = result.map((o, i) => (i === index ? updated : o));
  }
  return result;
}
```
